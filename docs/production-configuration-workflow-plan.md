# 制作配置与工作流优化实施清单

用户确认日期：2026-10-13。声音、Agent、模型参数和工作流规则均需页面操作；保持已有队列、权限、计费和质量校验。

## 默认制作偏好

- 视频模型直接生成对白、画外音、心声、环境声和动作音效。
- 配乐仅按已有设计生成；字幕默认在项目后期合成。
- 个人默认 → 项目 → 剧集 → 镜头/本次生成；明确继承与覆盖。
- 配置草稿、发布、版本历史、回滚；新任务使用发布版本，运行中固定配置快照。

## 交付状态和范围

本清单逐项对应 2026-10-13 用户确认的两轮优化建议。阶段只规定先后，不缩减总范围。

只有功能实现、权限与异常边界验证、实际页面操作验证通过，才能勾选。已有基础能力与新增交付分开记录；文档编写、页面控件出现、状态重置都不等于交付完成。依赖模型能力的项目必须说明参数控制、提示词约束或无法支持，不显示假成功。

## 已有基础与本轮目标的区别

2026-10-13 持续实施中：配置存储/API、声音策略接入、工作流快照、公共 LLM Agent 覆写和制作配置 UI 已落盘，但 A–G 的整体范围仍未完成，清单保持未勾选。当前环境已恢复 PostgreSQL/Redis，真实工作台能读取项目配置；完整页面保存/发布及多数执行场景尚未验收。单 worker 全量测试 148 个文件、722 项通过；类型检查与改动文件 ESLint 通过。最后新增的加载失败状态保护尚未复验。详见交接文档功能日志和下一步。

- 已有：队列、工作流步骤/attempt、执行锁、检查点、心跳、后台恢复、部分缓存和请求追踪。
- 已修复但未覆盖整个新方案：媒体手动重试使用新队列 ID；工作流重新生成清理目标及后续缓存、释放旧锁；保留成功前置步骤。
- 本轮新增：配置化和版本化、声音/Agent 页面全链路、请求级继续完成、能力真实映射及上述所有细分项。
- B15、C11、D07、D15、E11 等依赖外部模型能力的验收须记录支持范围；不能用“已配置”替代真实能力。

## 实施顺序

1. 配置版本和声音全链路。
2. Agent 页面编辑和实际请求生效。
3. 请求级执行、重试与恢复。
4. 并行、限流、缓存和预算。
5. 编排、历史对比、统计与通知。

## 完成标准

页面设置必须改变真实请求；持久化后刷新可恢复；运行任务不得被后续配置编辑改变；成功前置步骤保持有效；模型不支持的选项不得伪装成可执行功能。每项只在实现及验证后勾选。
