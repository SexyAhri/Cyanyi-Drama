# 视频声音与实际模型参数

视频任务默认使用项目内部的 `audioMode=full`，提示词包含对应镜头已有的对白、旁白、画外音、角色心声、环境声与动作音效。对白要求口型同步；旁白和心声来自画外，不驱动画面人物口型。字幕由后期合成。模型返回的原声在保存、剪辑和导出时保留；另行指定整集对白音轨时使用该音轨，避免两份对白叠加。

`audioMode` 是项目内部约定，各服务商只接收其实际接口支持的参数。

## AutoDL H3 多图生视频 15 秒

对照用户提供的工作流参数截图，工作流 ID 为 `minimax_h3_lightx2v_v5_15s`。

| 接口参数 | 实际支持 | 项目提交行为 |
| --- | --- | --- |
| `prompt` | 必填视频提示词 | 提交画面设计与完整声音要求 |
| `duration` | 整数 1–15 秒，默认 5 秒 | 按镜头时长生成，超出 15 秒先拆分 |
| `resolution` | `480p竖`、`480p横`、`480p(1:1)`、`768p竖`、`768p横`、`768p(1:1)`；默认 `768p竖` | 按分辨率和画幅映射；全局 `1080p` 在本工作流映射到 `768p`；审核显示实际档位 |
| `ref_image_0` | 必填图片 URL | 第一张参考图片 |
| `ref_image_1`–`ref_image_8` | 可选图片 URL | 按顺序最多提交 9 张，超限报错 |
| `seed` | 可选整数 | 请求提供整数时透传，不强制固定 |
| 音频开关 | 截图未列出 | 不发送 `audioMode` 或 `generate_audio` 等未列出的字段；在提示词要求声音，保留工作流返回的原声 |
| 音频参考 | 截图未列出 | 此工作流不接受 `ref_audio_*`；需要音频参考时使用对应的多图多音频工作流 |

提交：`POST /api/v1/comfyui/comfyui_workflow/minimax_h3_lightx2v_v5_15s`。

查询：`GET /api/v1/comfyui/comfyui_workflow/result/{task_id}`。按 `data.status` 判断完成，读取 `data.results[].url` 的视频结果。

## 其他协议

- 火山 Ark：项目 `audioMode=full` 对应真实参数 `generate_audio=true`。
- Agnes Video 2.5 Flash：[官方接口文档](https://wiki.agnes-ai.com/zh-Hans/docs/agnes-video-25-flash)列出 4–12 秒、固定 `720P`、最多 5 张图片与 3 段参考音频，未列出独立的生成音频开关。使用声音提示词和原声保留，不添加未声明字段。审核显示实际 `720P`。
- 自定义 OpenAI 兼容模板：提供布尔变量 `{{generate_audio}}`，模板可按服务商实际字段映射；不修改用户模板中的接口字段。

参数映射已通过本地请求测试，原声保留与后期合成已通过 FFmpeg 集成测试；这些测试不调用付费模型，不代表模型必然逐字生成或达到指定口型效果。
